BƯỚC 4: SỬA CODE ESP32 (2 phút)
================================

Mở file: esp32_firmware/smart_watering/smart_watering.ino

TÌM:
const char* SERVER_IP = "192.168.1.16";
const int SERVER_PORT = 5000;

THAY BẰNG:
const char* SERVER_URL = "https://smart-watering-xyz.onrender.com";
// ↑ Thay bằng URL thực tế của bạn!

Sửa hàm sendDataToServer():

TÌM:
String url = String("http://") + SERVER_IP + ":" + SERVER_PORT + "/api/sensor-data";

THAY:
String url = String(SERVER_URL) + "/api/sensor-data";

TÌM:
String url = String("http://") + SERVER_IP + ":" + SERVER_PORT + "/api/command";

THAY:
String url = String(SERVER_URL) + "/api/command";

🐛 TROUBLESHOOTING
==================

Lỗi: ESP32 không kết nối được Render (HTTPS issue)
---------------------------------------------------

Thêm vào đầu file ESP32:
#include <WiFiClientSecure.h>

Sửa hàm sendDataToServer():
WiFiClientSecure client;
client.setInsecure();

HTTPClient http;
http.begin(client, url);  // Dùng client
// ... phần còn lại giữ nguyên

---

Lỗi: Render build failed
-------------------------

Kiểm tra log trong Render Dashboard → Logs
Thường do version package không tương thích.
